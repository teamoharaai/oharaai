# Canonical brand-logo review

This development-only Expo Router root renders the complete OHARA semantic logo
family without adding a production route.

Run `npm run preview:brand`, then open:

- `/?appearance=light`
- `/?appearance=dark`

The review includes the three supplied Home, Momentum, and Constellation vectors
alongside the retained production artwork at 16, 20, 24, 32, and 48 pixels,
plus representative Sidebar, feature-header, Home-card, Global Create, and
Ohara Intelligence contexts.
