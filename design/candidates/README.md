# Candidates

Early-stage feature *concepts* — ideas being evaluated before they earn a full
design lane (like `design/circles/` or `design/goal-detail-redesign/`). A
candidate is a "why/why-not + risks" writeup, not a build plan. Once a candidate
is signed off, it graduates to its own top-level `design/<feature>/` folder.

Organized by the five main features so each idea lives next to the pillar it
extends:

- `goals/` — the atomic unit of behavior (milestones + Tasks)
- `projects/` — long-term ambition containers that aggregate goals
- `echo/` — standalone journaling (Bud/Rose/Thorn)
- `momentum/` — Today's Focus / Next Step momentum surface
- `roots/` — (reserved)

Each candidate is one Markdown file named after the concept
(e.g. `projects/pdf-to-goals.md`).
